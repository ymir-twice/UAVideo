# VideoBuddy 前端设计规格

## 概述

VideoBuddy 是一个基于 Vue 3 + Naive UI 的视频理解智能体 Web 界面，提供视频上传/URL 导入、智能分析和 GPT 风格对话功能。

## 3. 功能流程

### 3.1 纯文本对话（默认）

1. 用户直接在输入框输入问题
2. 点击发送或按 Enter
3. AI 流式返回回复，显示在聊天区
4. 消息保存到对话历史

### 3.2 视频理解模式

1. 用户上传视频文件或粘贴 URL
2. 显示视频预览（缩略图 + 文件名/链接）
3. 点击"开始分析"
4. 底部状态栏显示处理进度：
   - `抽帧中...`
   - `生成Caption...`
   - `音频转写...`
   - `构建记忆...`
   - `分析完成`
5. 分析完成后，显示结构化结果卡片
6. 用户可继续就视频内容进行对话

## 4. 组件清单

### 4.1 Header
- Logo 图片（左侧）
- 标题 "VideoBuddy"
- 历史对话按钮（右侧，图标 + 文字）

### 4.2 VideoUploader
- 拖拽区域（虚线边框，hover 时高亮）
- 或 URL 输入框 + 确认按钮
- 上传后：显示预览 + 文件名 + [开始分析] 按钮
- 支持格式：mp4, avi, mov, webm

### 4.3 MessageBubble
- 用户消息：右对齐，灰色背景 `#3f3f46`
- AI 消息：左对齐，深色背景 `#292524`，圆角 12px
- 支持 markdown 渲染
- AI 消息支持流式输出（逐字显示）
- 复制按钮（hover 时显示）

### 4.4 StatusBar
- 固定在底部
- 空闲时：显示 "VideoBuddy 已就绪"
- 处理时：显示进度条 + 当前阶段文字
- 高度 32px，背景 `#1f1d1c`

### 4.5 ChatInput
- 多行文本输入框
- 自动增高，最大 200px
- 发送按钮（右侧）
- 支持 Ctrl+Enter 发送

### 4.6 HistoryDrawer
- 右侧抽屉式侧边栏
- 按日期分组的历史对话
- 点击加载历史对话

### 4.7 AnalysisResultCard
- 视频分析结果展示
- 包含摘要、标签、处理统计

## 5. 技术栈

- **框架**: Vue 3 + Composition API + TypeScript
- **构建**: Vite
- **UI 库**: Naive UI（暗黑主题定制）
- **状态管理**: Pinia
- **HTTP**: Axios
- **Markdown**: marked + highlight.js
- **样式**: SCSS / CSS Variables

## 6. 状态管理 (Pinia Store)

### sessionStore

```typescript
interface SessionState {
  // 当前会话
  currentSessionId: string | null;
  messages: Message[];
  isProcessing: boolean;
  processingStatus: string;
  processingProgress: number;

  // 视频状态
  videoFile: File | null;
  videoUrl: string | null;
  analysisResult: AnalysisResult | null;

  // 历史
  sessions: Session[];
}

// Actions
createSession(): string;
sendMessage(content: string): Promise<void>;
uploadVideo(file: File): Promise<void>;
analyzeVideo(): Promise<void>;
loadHistory(): Promise<void>;
```

## 7. API 对接

| 端点 | 方法 | 描述 |
|------|------|------|
| `/health` | GET | 健康检查 |
| `/sessions` | POST | 创建新会话，上传视频 |
| `/sessions/:id` | GET | 获取会话状态和记忆 |
| `/sessions/:id/question` | POST | 发送问答 |
| `/sessions/:id/stream` | GET | SSE 流式输出处理进度 |
| `/sessions/:id/memory` | GET | 获取记忆可视化数据 |

## 8. 动画效果

- 消息气泡：fadeIn + slideUp，200ms ease-out
- 状态栏过渡：opacity 切换，150ms
- 发送按钮：hover 时 scale(1.05)，点击 scale(0.95)
- 抽屉滑入：slideInRight，250ms ease-out
- 流式文字：逐字显示，50ms/字符
